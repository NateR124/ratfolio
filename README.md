# Ratfolio

What if you made a site, where you navigated by clicking pictures of rats in paintings?

This was made in a night using Gemini for the art, Suno AI for the music, and Claude Code for the code.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech

Next.js 16 / React 19 / Tailwind 4 / Framer Motion / Web Audio API
